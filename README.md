# Kiro University Challenge 2026

Submission repo for the [Kiro University Challenge](https://kiro.dev/2026/university/).

The whole build is done in Kiro, on the free plan, with the artifacts the lessons ask for
committed to this repo as they are produced. Everything below is generated by Kiro or written
while driving Kiro, and points at the file that proves it.

## Lesson artifacts

| Lesson | Artifact | Status |
| --- | --- | --- |
| 1. Spec-driven development | `.kiro/specs/<feature>/{requirements,design,tasks}.md` | pending final prompt |
| 2. Steering documents | `.kiro/steering/*.md` | see `.kiro/steering/` |
| 3. Hooks | `.kiro/hooks/*.json` | pending final prompt |
| 4. Property-based testing | property tests generated in the Kiro IDE | pending final prompt |
| 5. Powers | power installed from the registry and used in the build | pending final prompt |
| 6. Model Context Protocol | `.kiro/settings/mcp.json` + a server used in the build | pending final prompt |
| 7. Custom agents | `.kiro/agents/<name>.json` + an agent used in the build | pending final prompt |

## What this repo is

The Kiro University Challenge drops a final prompt partway through the week and asks for a
working project built with Kiro's spec-driven workflow. This repository is that project: the spec
comes first, the tasks come from the spec, and the code follows the tasks.

## Working conventions

Steering files in `.kiro/steering/` describe how work is done here, so any Kiro agent working in
this repository follows the same conventions without being told twice.
